# La trama digital

Sitio web académico sobre el impacto de las tecnologías web en la sociedad y los negocios. Examina una clase en línea, un catálogo comercial y un pedido ilustrativo en un taller de Riobamba.

## Abrir el sitio

Abre `index.html` en un navegador moderno. Mantén las carpetas `pages`, `images`, `videos`, `css` y `js` junto al archivo de inicio. El video, las imágenes y las páginas están disponibles sin conexión.

## Páginas

- **Inicio** presenta los temas y un video de 32 segundos.
- **Sociedad** analiza las oportunidades y barreras de un aula virtual.
- **Negocios** compara la venta presencial y la venta mediante un catálogo web.
- **Caso local** sigue un pedido artesanal ficticio en Riobamba.
- **Contacto** permite probar un formulario con validación nativa de HTML. La confirmación es local. Los datos no se envían ni se almacenan.

Los créditos de las imágenes y del video se encuentran en `images/creditos.txt`.
